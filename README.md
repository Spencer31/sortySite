# Puzzler website

Static marketing, support, and legal site for **Puzzler: Sort and Match Tiles**.

## Preview

Serve the repository root with any static web server. For example:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## App Store Connect URLs

After deployment, use these public HTTPS URLs:

- Marketing URL: `/`
- Support URL: `/support.html`
- Privacy Policy URL: `/privacy.html`
- User Privacy Choices URL (optional): `/privacy-choices.html`

The app should also expose the privacy-policy link in an easily accessible location, such as Settings or About, to meet App Review Guideline 5.1.1(i).
